# Groupes de Sécurité

Des groupes de sécurité globaux ont été créés pour faciliter l'attribution future des permissions d'accès aux ressources réseau.

| Nom du Groupe | Type | Portée | Emplacement (OU) | Rôle / Description |
| :--- | :--- | :--- | :--- | :--- |
| **GRP-RH** | Sécurité | Global | RH | Regroupe les collaborateurs des Ressources Humaines |
| **GRP-IT** | Sécurité | Global | IT | Regroupe les techniciens et administrateurs du service IT |
| **GRP-Direction** | Sécurité | Global | Direction | Regroupe les membres de la direction |
