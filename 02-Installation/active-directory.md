# Installation et Promotion d'Active Directory (AD DS)

## Rôles installés
* **Service :** Active Directory Domain Services (AD DS)
* **Type de déploiement :** Ajout d'une nouvelle forêt
* **Nom du domaine racine :** entreprise.local
* **Niveau fonctionnel de la forêt / du domaine :** Windows Server (par défaut)
* **Fonctionnalités associées :** Serveur DNS, Outils de gestion d'administration distante (RSAT)
