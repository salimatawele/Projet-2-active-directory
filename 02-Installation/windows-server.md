# Installation de Windows Server

## Informations générales
* **Système d'exploitation :** Windows Server (2019 / 2022) Standard / Datacenter
* **Type d'installation :** Expérience bureau (Desktop Experience)
* **Hyperviseur utilisé :** VirtualBox (avec installation des outils d'intégration/Additions invité)
* **Nom d'hôte initial :** SRV-DC01
