# Projet-2-active-directory
This project focuses on setting up and managing a Windows Server 2022 infrastructure with Active Directory. It includes Active Directory, DNS, DHCP, user and group management, Organizational Units (OUs), Group Policy Objects (GPOs), network shares, permissions, and security tests.

## Présentation

Mise en place d'une infrastructure Windows Server basée sur
Active Directory Domain Services (AD DS).

Le projet comprend :

- Windows Server 2022
- Active Directory Domain Services
- DNS
- DHCP
- Gestion des utilisateurs et groupes
- Organisation par OU
- Group Policy Objects (GPO)
- Partages réseau
- Gestion des permissions
- Tests de sécurité et de fonctionnement
